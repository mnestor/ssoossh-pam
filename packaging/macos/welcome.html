This installs pam_ssoossh @VERSION@, a PAM module that authenticates sudo and SSH logins through an approval in a browser, against an ssoosshd server. It was qualified against ssoosshd @COMPAT@.

It installs only files. Nothing is enabled until you add one line to a pam.d file, and the next pane says which line and where.

Built for @TARGET@: Apple silicon, macOS @MINVER@ or later. It links only what ships with macOS and needs nothing else installed.
